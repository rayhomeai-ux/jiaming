# 嘉名・寶寶取名工具

> 「皇覽揆余初度兮，肇錫余以嘉名。」——屈原《離騷》

一個純前端的取名輔助網站：任何姓氏都能用，依康熙筆劃計算五格、三才、陰陽、字五行、生肖字根與八字粗算，並比對內政部姓名統計找出菜市場名和長輩常用名。家人可以在同一個網頁上投票討論。

結果只供參考；各派姓名學說法不同，頁面上方的判斷標準都可以切換。

## 功能

| 分頁 | 內容 |
| --- | --- |
| 名字健檢 | 輸入姓名，檢查五格、三才、筆劃陰陽、字五行、生肖字根、聲調、同音詞、詩詞出處、菜市場名、年代感、撞名 |
| 候選產生 | 依目前的判斷標準自動組合名字並排序；可指定必含字、排除字、自選字，預設排除菜市場名與長輩用字 |
| 八字粗算 | 輸入出生日期時間，粗估日主強弱與喜用五行，可一鍵套用到判斷標準 |
| 已討論名單 | 收藏的名字與討論過的名字，可整組提名到家族投票，或複製後貼到 LINE |
| 家族投票 | 每個名字投「喜歡／可以／不喜歡」並留言，結果存在你的 Google 試算表 |

## 檔案

```
index.html           網站本體（所有計算都在瀏覽器裡進行）
chars.json           13,048 個 Big5 字的康熙筆劃、五行、部首、拼音
pairs.json           兩字同句的詩詞索引
poems.json           詩詞句子
words.json           同音詞比對用的常用詞
config.js            投票後端網址（部署 Apps Script 後填入）
sheets-backend.js    把投票接到 Google 試算表的轉接層
apps-script/Code.gs  投票後端程式，貼到 Google Apps Script
```

## 開啟網站（GitHub Pages）

1. 儲存庫 **Settings → Pages**。
2. **Source** 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/(root)`，按 **Save**。
3. 等一兩分鐘，網址會是 `https://rayhomeai-ux.github.io/jiaming/`。

不設定投票也能用：健檢、候選產生、八字、名單都在瀏覽器裡算，不需要後端。

## 設定家族投票（Google 試算表＋Apps Script，免費）

只要設定一次，家人之後只需要網址和通關碼，不用註冊任何帳號。

1. 用你的 Google 帳號建立一份新的 Google 試算表，例如命名「嘉名投票」。
2. 試算表選單 **擴充功能 → Apps Script**。
3. 把編輯器裡預設的程式全部刪掉，貼上本儲存庫 `apps-script/Code.gs` 的內容，按儲存。
4. 左側 **專案設定（齒輪）→ 指令碼屬性 → 新增指令碼屬性**，加兩個：
   - `FAMILY_CODE`：給家人用的通關碼（建議 8 碼以上、英數混合）
   - `ADMIN_CODE`：你自己用的管理碼（用它進入投票頁，可以移除任何人提名的名字）

   通關碼不要寫進這個儲存庫，它是公開的。
5. 右上 **部署 → 新增部署作業**，類型選 **網頁應用程式**：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
6. 按部署，第一次會要求授權存取試算表，請用自己的帳號同意。
7. 複製「網頁應用程式網址」（結尾是 `/exec`），填進 `config.js` 的 `url`，推送到 GitHub。
8. 打開網站的「家族投票」分頁，輸入通關碼，填好「你的稱呼」，就能提名和投票。

部署完成後，在 Apps Script 編輯器上方的函式選單選 `checkSetup`，按「執行」一次。它會觸發授權，並在「執行記錄」顯示兩組通關碼是否設定好、長度夠不夠（不會印出通關碼本身）。

### 更新 Code.gs

1. 打開試算表 → **擴充功能 → Apps Script**，把 `Code.gs` 全部換成新版，按儲存。
2. **部署 → 管理部署作業**，選現有的那個部署作業，按鉛筆圖示 **編輯**。
3. **版本** 選 **新版本**，按 **部署**。網址不變，`config.js` 不用改。
4. 如果跳出授權視窗，選自己的帳號並允許。
5. 函式選單選 `checkSetup`，按 **執行**，確認執行記錄沒有錯誤。

不要按「新增部署作業」，那會產生新網址，網站就連不到了。

### 防暴力猜碼

10 分鐘內通關碼錯誤累計 30 次，後端會暫停受理所有請求，直到連續 10 分鐘沒有新的錯誤嘗試。家人看到「已暫時鎖定」時等 10 分鐘即可；想立刻解除，在編輯器執行 `resetLock`。

投票資料存在試算表的 `data` 工作表；每次有人投票，`結果` 工作表會自動整理成排名、誰投了什麼和留言。

## 安全與隱私

- 網站和這個儲存庫都是公開的，任何人都能看程式碼與「已討論名單」。不要把出生日期、時辰、通關碼、金鑰放進儲存庫。
- 只有儲存庫擁有者和你邀請的協作者能修改內容；外人只能 fork 或開 Issue／Pull Request，不合併就不會改變任何東西。
- 投票資料不在 GitHub，在你的 Google 試算表裡。沒有通關碼的人讀不到也寫不進去。
- `Code.gs` 開頭的 `@OnlyCurrentDoc` 讓程式只能存取綁定的這份試算表，碰不到你雲端硬碟的其他檔案。
- `config.js` 裡的 Apps Script 網址是公開的，但它只是部署代碼，看不出試算表位置或你的帳號；試算表本身不要按「共用」。
- 通關碼擋得住外人，但不是嚴格的身分驗證：知道通關碼的人換一台裝置就能再投一次。家人之間使用沒問題。
- 八字粗算只在瀏覽器裡計算，輸入的出生資料不會送出。

## 在自己電腦上執行

```bash
python -m http.server 8000
# 打開 http://localhost:8000/
```

直接雙擊 `index.html` 不行，瀏覽器會擋下讀取 JSON 資料檔。
